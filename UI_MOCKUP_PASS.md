# SlipCut approved UI fidelity pass

This branch changes presentation only. Selection, booking, SportyBet provider, risk ranges, market restrictions, Engine ladder generation, and stored slip behavior are unchanged.

The visual pass is aligned to the approved mobile mockups:

- flat warm-cream application canvas
- compact SlipCut wordmark and bare notification icon
- plain Football/Basketball segmented switch on Build
- black target-odds chips with gold selected state
- simplified custom-odds, risk, date-window, and main action treatment
- image-like Football/Basketball sport cards
- centered secondary page titles and bare back controls
- header-triggered game search, compact league filters, team-style match badges, and compact odds chips
- compact Slip Builder with team badges, Single/Full toggle, add-more-games control, summary and booking action
- simplified Cut/Trim default surface with recent slips
- clean Engine ladder without analytics stat cards
- compact My Slips cards
- flat four-item bottom navigation
